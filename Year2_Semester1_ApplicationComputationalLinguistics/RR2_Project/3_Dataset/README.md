# 3_Dataset — Benchmark Ontologies, Processed Representations, and Reference Alignments

## 1. Overview

This directory contains the benchmark ontology datasets, extracted entity representations, and ground-truth reference alignments used by the Agent-OM local replication and $\le 4\text{B}$ model evaluation pipeline.

All files in this directory are strictly read-only scientific inputs. Experimental predictions and intermediate logs are written to `4_Temporary/` and `5_Results/`, never into `3_Dataset/`.
